## Visa appointment checker
This repository includes a simple script `visa_checker.py` that checks a given URL for available visa appointments and emails you if an appointment is found.

### Setup
Install dependencies: 
```bash
pip install -r requirements.txt
```

Edit `visa_checker.py` to fill in your target URL and email credentials. Then run:
```bash
python visa_checker.py
```
